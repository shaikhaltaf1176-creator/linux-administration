# Introduction to Linux

## What is Linux?

Linux is an open-source operating system based on the Linux kernel. It manages computer hardware and software resources and allows users to interact with the system.

Linux is widely used in servers, cloud computing, networking, cybersecurity, and software development.

## Features of Linux

- **Open Source:** Its source code is freely available.
- **Multiuser:** Multiple users can access the system.
- **Multitasking:** Runs multiple processes simultaneously.
- **Secure:** Provides user permissions and access control.
- **Portable:** Supports different hardware platforms.
- **Stable:** Commonly used for systems that need continuous operation.

## Where is Linux Used?

- Web servers
- Cloud platforms (AWS, Azure, GCP)
- Supercomputers
- Android devices
- Networking devices
- Development environments

## Linux vs Windows

| Linux                   | Windows                       |
| ----------------------- | ----------------------------- |
| Open source             | Proprietary                   |
| Commonly uses CLI       | Commonly uses GUI             |
| Highly customizable     | More restricted customization |
| Popular for servers     | Popular for desktop computers |
| Distributions available | Different Windows editions    |

## Basic Linux Commands

| Command  | Purpose                    |
| -------- | -------------------------- |
| `pwd`    | Display current directory  |
| `ls`     | List files and directories |
| `cd`     | Change directory           |
| `mkdir`  | Create directory           |
| `touch`  | Create a file              |
| `clear`  | Clear terminal             |
| `whoami` | Display current user       |
| `date`   | Display date and time      |

## Conclusion

Linux is an important operating system for system administrators and cloud engineers. Learning Linux fundamentals helps build a strong foundation for server administration and cloud computing.
