# Basic Linux Commands

## Overview
Linux commands are used to interact with the operating system through the terminal. They help administrators manage files, monitor the system, and perform daily tasks.

## Commands

| Command | Description |
|---|---|
| `pwd` | Displays the current working directory |
| `whoami` | Displays the current logged-in user |
| `date` | Displays the current date and time |
| `cal` | Displays the calendar |
| `uname` | Displays system information |
| `uname -a` | Displays detailed system information |
| `hostname` | Displays the system hostname |
| `clear` | Clears the terminal screen |
| `history` | Displays previously executed commands |
| `uptime` | Shows how long the system has been running |
| `who` | Shows currently logged-in users |
| `id` | Displays user and group IDs |
| `free -h` | Displays memory usage |
| `df -h` | Displays disk space usage |
| `top` | Monitors running processes |

## Practical Examples

```bash
# Check current directory
pwd

# Check logged-in user
whoami

# Display system information
uname -a

# Check system uptime
uptime

# Check memory usage
free -h

# View command history
history
```
